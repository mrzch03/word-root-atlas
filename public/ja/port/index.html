英単語の語源図鑑 / PORT

import と transport に、同じ語根が隠れている？

ふたつの英単語に共通するのは port。ラテン語の portāre「運ぶ」にさかのぼります。運ぶ向きが変わると、どんな単語になるでしょう。

横にスワイプするか、下の単語を選んでみましょう。port はその場に残ります。
imextransport
import
im- は「中へ」。品物を中に運び入れることから「輸入する」。
export
ex- は「外へ」。品物を外に運び出すことから「輸出する」。
transport
trans- は「越えて」。ある場所から別の場所へ運ぶことから「輸送する」。

壺を運ぶ人たち

ローマの港に、帆を張った船が停まっています。岸壁には、取っ手が二つ付いた壺を運ぶ人たち。荷物は船に積まれ、海を渡り、別の港へ運ばれます。そんな「運ぶ」という動きを、一つのミニチュアにしました。

絵の舞台は港ですが、この三つの単語の語源をたどると、港を表すラテン語 portus ではなく、動詞 portāre に行き着きます。
